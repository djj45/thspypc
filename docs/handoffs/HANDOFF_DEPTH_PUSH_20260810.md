## 个股集合竞价三行盘口

### 外层与股票块定位

外层魔数：

```text
09 7b d0 0f 7f
```

股票块不是永远从固定绝对偏移开始。抓包中代码位置包括但不限于：

- `C=45`：普通单记录；
- `C=51` / `C=57`：分别可承载 2/3 条 delta 记录；
- `C=213`：前面带状态文本或紧凑记录的变长帧。

生产解析不再搜索这些偏移；这里仅保留为抓包定位信息。实际流程是先展开为
`hd1.0` 定长行，再按字段表和标准行偏移解析。

### 已验证字段（旧版原始单记录偏移）

| 相对位置 | 含义 |
|---|---|
| `C+6` | 昨收 |
| `C+10` | 虚拟撮合价 |
| `C+22` | 普通现价；集合竞价时为 0 |
| `C+26` / `C+30` | 买一虚拟撮合价 / 撮合量 |
| `C+34` / `C+38` | 买二缺省哨兵 / 买方未匹配量 |
| `C+50` / `C+54` | 卖一虚拟撮合价 / 撮合量 |
| `C+58` / `C+62` | 卖二缺省哨兵 / 卖方未匹配量 |
| `C+126` | 打包的未匹配方向与数量 |

`C+126` 中 `0x08000000` 表示卖方，低 27 位为数量；未置位表示买方。显式的
买二/卖二数量槽优先，打包字段用于校验和紧凑变体回退。

竞价第二行没有有效委托价，生产解析结果用 `price=None` 表示，不应伪造为撮合价。

## 71B 集合竞价撤单推送

子类型 `09 7b d0 01 60` 与普通逐笔成交的 `... 7f` 不同。2026-08-10 的 171 帧均为
`002428`，通过客户端挂单/撤单列表的撤单时刻、存续时长、价格和手数逐条对齐：

| 偏移 | 含义 |
|---|---|
| `[5]` | `0x08=买撤`，`0x0c=卖撤` |
| `[28] + [29:35]` | 外层市场和代码 |
| `[39:43]` | 推送序号 |
| `[43] + [44:50]` | 事件市场和代码，与外层一致 |
| `[50:54]` | 原委托 Unix 时间戳 |
| `[54:58]` | 撤单 Unix 时间戳 |
| `[58:62]` | 撤单价格（THS float） |
| `[62:66]` | 撤单数量（股） |
| `[66:70]` | 辅助 ID；当前 UI 不显示，精确语义暂不命名为委托 ID |
| `[70]` | 结束符 `0x7d` |

客户端“买撤/卖撤”旁的 `30s`、`1m`、`4m` 等文字就是
`撤单时间 - 原委托时间`。生产 API `parse_auction_cancel_push()` 同时返回时间戳、
`datetime`、`lifetime_seconds`、股数和手数。


