# 同花顺 PC 版功能复刻路线图（缺口对照表）

> 对照同花顺 Windows PC 免费版（hexin），盘点 `thspypc` 的实现现状与缺口，
> 作为后续补全的优先级依据。本文档随实现进度更新。
>
> 生成日期：2026-07-28（基于 `feat/stock-list-full` 分支 commit `6d74d82`）。

## 口径说明

- **目标**：基本复刻**同花顺 PC 免费版**的核心行情功能，不是手机版、不是通达信。
- **大单/资金流口径**：PC 版分时图只有一条「大单金额」曲线（主力净额=主动买额−主动卖额），
  **不分**超大单/大单/中单/小单（那是手机版/通达信的口径）。因此个股层面的资金流
  在 PC 版复刻目标里**已达标**，无需按四档拆分。

## ⚠️ 部分实现

| 模块 | 方法 | 现状 | 缺什么 |
|------|------|------|--------|
| 历史分时（回忆） | `history_timeline` | 指数定长帧（1A0002 类）可解 | 个股 level2 变长帧（如 000938，记录 93/94 字节交替）逐点解码待优化；请求能正确发出并拿到原始响应 |

## ❌ 缺口（离"基本复刻 PC 版"还差的）

### 1. 系统板块（行业/概念板块）— 最大缺口

PC 版左侧导航的核心功能，当前 `blocks.py` 只覆盖**自定义**板块/自选股，**完全不含**系统板块。

| 子能力 | 状态 | 说明 |
|--------|------|------|
| 申万一/二/三级行业板块列表 | ❌ | 无 |
| 概念板块列表（半导体/人工智能/新能源…） | ❌ | 无 |
| 按板块查成分股 | ❌ | `query_dynamic_plate("半导体")` 是问财实时选股匹配，非"系统板块成分股"语义 |
| 板块行情（指数/涨跌幅排行） | ❌ | 无 |
| 板块资金流 | ❌ | 无（依赖系统板块能力） |

> 系统板块走 `basic.10jqka.com.cn` 行业/概念接口或本地 `block_hq` 缓存，
> `blocks.py` 中无相关常量或代码。需要新增独立模块对接。

### 2. 盘口/十档买卖盘（协议层已就绪，未暴露）

| 子能力 | 状态 | 说明 |
|--------|------|------|
| 十档买卖盘 | ⚠️ 协议层已实现 | `build_depth_quote_query` + `parse_depth_quote_response` 已在 `protocol.py`，但 `client.py` 无 public 门面方法 |
| 逐笔成交/委托（Level2） | ❌ | L2 账号有权限，但未实现 |

## 📊 优先级建议

按"复刻同花顺常用功能"的性价比和重要性排序：

| 优先级 | 模块 | 理由 |
|--------|------|------|
| 🔴 P0 | **系统板块（行业/概念）** | PC 版核心导航功能，缺口最大；需先调研系统板块接口协议 |
| 🟡 P1 | **盘口/十档** | 协议层已实现，封装成本极低，立即可用 |
| 🟡 P1 | **个股资金流历史/排名** | 个股主力净额曲线已有，补历史/排名即完整 |
| 🟢 P2 | **龙虎榜** | 重要但非每日必用 |
| 🟢 P2 | **逐笔成交/委托（L2）** | L2 账号已具备权限，是差异化能力 |
| ⚪ P3 | **F10/基本面** | 工作量大，多走 HTTP 接口，与行情协议栈独立 |
