## 目标

做一个同花顺风格的行情看板 HTML 页面，简单展示 thspypc 拿到的实时数据。

## 方案：Python http.server + 单 HTML 页面

不引入新依赖，用 Python 内置 `http.server`。一个脚本 `tests/web_dashboard.py`：

### 后端（Python）
- 启动时读 `.env` 登录 THSClient（connect 含 init 握手）
- HTTP 服务两个路由：
  - `GET /` → 返回内嵌的 HTML 页面
  - `GET /api/quotes` → `list_quotes`（自选股行情，代码列表可配置）
  - `GET /api/hot` → `stock_list_hot`（热门股排序）
  - `GET /api/dxjl` → `dxjl_latest`（短线精灵最新异动）
- 前端每 3-5 秒轮询 API 刷新数据

### 前端（单个 HTML，内嵌 CSS+JS）
**同花顺风格**：
- 深色背景（#1a1a2e 类似）
- 红涨绿跌（中国习惯：涨=#e62e4d 红，跌=#00a870 绿）
- 紧凑表格、等宽数字字体
- 三个区域（tab 切换或上下排列，简单优先）：
  1. **自选行情表**：代码 | 名称 | 现价 | 涨幅% | 昨收 | 开盘
  2. **热门股列表**：stock_list_hot 返回的排序代码
  3. **短线精灵异动**：时间 | 代码 | 类型 | 金额 | 涨幅（滚动列表）

### 数据结构（从代码确认）
- `list_quotes` → `[{code, dt10(现价), dt6(昨收), dt7(开盘), dt66(涨幅), dt17(竞价量)...}]`
- `stock_list_hot` → `[{code, name, market}]`
- `dxjl_latest` → `[{时间, 代码, 异动类型, 金额, 涨幅...}]`
- 涨幅 = `(dt10 - dt6) / dt6 * 100`，由后端算好返回

### 配置
- 默认自选股：几只常见的（600000 浦发银行、000001 平安银行 等）
- `--codes` 参数可自定义
- `--port` 默认 8888

### 不做的事
- 不做实时推送（WebSocket）——用轮询更简单，3-5s 够用
- 不做交易功能——只读展示
- 不引入前端框架——纯原生 HTML/CSS/JS
