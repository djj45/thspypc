## 实现内容

### 一、全市场列表界面 `tests/web_stocklist.py`（新建，核心交付）

复用 `web_dashboard.py` 零依赖模式（`http.server` + 内嵌原生 HTML/JS，不引入框架）。

**后端**：
```
启动: connect() → stock_list_cached() 拿 7400 条 code+name（瞬时缓存）
      → 前端首屏（9列，数值列空）
      → 后台线程分批 list_quotes 回填（每批30，按市场分组 17/22/33/151）
      → 每批更新内存缓存
GET /api/stocks   → 全量数组（渐进填充）
GET /api/progress → {loaded, total, pct}
```

**前端表头列**（只列直接返回的字段，按你要求）：
代码 · 名称 · 最新价 · 今开 · 最高 · 最低 · 昨收 · 成交量(手) · 成交额(元)

数值映射：
- 最新价=dt10、今开=dt7、最高=dt8、最低=dt9、昨收=dt6
- 成交量=round(dt13/100) 手、成交额=dt19 元

**表头排序**（前端纯本地排序）：
- 每列定义 sort key（数值/字符串）
- 点击切换升降序，默认按成交额降序（抓包确认涨幅前最常排序列）
- 当前列高亮 + 箭头

**虚拟滚动**（纯 JS 手写，7400 行不卡）：
- 视窗渲染（可视区 + 上下缓冲），滚动动态计算行范围
- 行高固定，scrollTop ÷ 行高 = 起始行

**样式**（复用 web_dashboard 同花顺风格）：
- 深色底、涨红跌绿（当前框架版无涨跌幅列，价格/开/高/低 暂用中性色；补涨幅列后上红绿）
- 成交额格式化（亿/万）、成交量万手、进度条"行情加载 N/7400"
- 手动刷新按钮（盘中重拉）

**健壮性**：
- market=None（北交所/基金）的 list_quotes 不支持 → 保留 code+name，数值列显示 --
- 每批 try/except，单批失败不影响整体
- 沪 17/22、深 33 用 `market_from_code` 派生
